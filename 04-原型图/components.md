# 组件规范

> 与 `design-system.md` 配套，最终实现（Element Plus + 自定义变量）需 1:1 复刻本规范。

## 按钮 Button

| 类型 | 高度 | 内边距 | 圆角 | 底色 | 文字 | 边框 |
|---|---|---|---|---|---|---|
| 主按钮 | 32 / 36 | 0 14 | 6 | `#174A5C` | `#fff` | 无 |
| 次级 | 32 | 0 14 | 6 | `#fff` | `#174A5C` | `#CFE0E1` |
| 文字 | 32 | 0 8 | 4 | 透明 | `#316B74` | 无 |
| 危险描边 | 32 | 0 14 | 6 | `#fff` | `#A62B32` | `#A62B32` |
| 禁用 | 32 | — | 6 | `#E8F1F1` | `#9BB0B4` | 无 |

行内操作最多「查看 + 2 个高频操作」，其余收进「更多」下拉。

## 表单 Form

- 标签宽 110px，右对齐，冒号；必填项标签前红色 `*`。
- 输入高 34px，圆角 6px，边框 `#DCE7E7`，focus 边框主色 + `0 0 0 2px rgba(42,127,134,.15)`。
- 校验失败：边框 `#A62B32`，下方 12px 红字说明。
- 数字输入右对齐、等宽数字；金额带两位小数。
- 关闭抽屉/切换路由前检测未保存内容。
- 复杂表单提供「保存草稿」与「提交」两个主次按钮。

## 表格 Table

- 表头高 40px，背景 `#F3F8F8`，字重 600，12px。
- 行高 44px，斑马纹 `#F7FBFB`，hover `#E8F1F1`。
- 表头不写死宽度：`min-width` + 允许横向滚动；编号/状态/日期/操作列 `nowrap`。
- 分页：右下角，默认 10 条，可切 20/50；显示「共 N 条」。
- 数字列右对齐，文本列左对齐，状态列居中。

## 卡片 Card

白底，圆角 8px，边框 `#E4EEEE`，内边距 18px，标题 15px/600 + 右上角操作区。
KPI 卡片：标签 12px 灰、数值 26px/600 等宽、环比小字（上升 `#A62B32`，下降 `#247A58` —— 采购场景金额上升用红）。

## 标签 Tag

高 22px，内边距 0 8，圆角 4，12px。映射：

| 状态 | 底色 | 字色 |
|---|---|---|
| 草稿 / 待下单 | `#EDF3F3` | `#5B7176` |
| 待审批 / 报价中 | `#FBF2DF` | `#A9761F` |
| 执行中 / 待比价 | `#E8F1F1` | `#174A5C` |
| 已完成 / 已通过 / 合格 | `#E4F3EC` | `#247A58` |
| 驳回 / 作废 / 不合格 | `#FBE9EA` | `#A62B32` |
| 部分到货 / 待结单 | `#EAF2F8` | `#316B74` |

## 弹窗 Dialog / 抽屉 Drawer

- 弹窗宽 480 / 640，圆角 8，`0 8px 24px rgba(23,74,92,.16)`，遮罩 `rgba(16,42,49,.45)`。
- 抽屉宽 560（表单）/ 720（比价/审批），右侧滑入，头部固定，底部操作条固定。
- 审批抽屉内必须同时展示单据摘要，避免审批人来回切页。
- 危险操作弹窗：红色描边确认按钮 + 原因输入（≥5 字）。

## 分页 Pagination

右下；尺寸 28px；当前页主色实底；含总数与每页条数切换。

## 时间轴 Timeline

左侧 2px 竖线 `#DCE7E7`，节点 8px 圆点（当前事件主色实心，历史空心）。
每条：事件名（13/600） + 操作人 + 时间（12px 灰） + 原因（12px，退回/作废类必填）。

## 空状态 Empty

居中，图标 48px 线性，主文案 14px「当前筛选条件下无记录」，副文案 12px 说明下一步，主按钮「新建询价比价单」。

## 选择器 Select

搜索下拉宽 180–240px；多选显示折叠标签（超过 2 个显示 +N）；日期区间用范围选择器，不用两个文本框。

## 文件上传 Upload

拖拽区高 96px，虚线 `#CFE0E1`，hover 主色；显示进度、类型限制（图片 JPG/PNG、附件 PDF/XLSX）、大小限制（图片 5MB、附件 20MB）；已上传显示文件名 + 大小 + 删除（二次确认）。禁止出现让人手填 URL 的输入框。
