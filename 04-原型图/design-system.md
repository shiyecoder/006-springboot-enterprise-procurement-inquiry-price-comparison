# 设计系统 · 企业采购询价比价与审批管理系统

> 视觉方向取自需求文档「UI 视觉与交互设计」：医疗青蓝，专业业务系统风格。
> 关键词：数据可读性、操作效率、状态辨识。不用巨幅口号、装饰光效、悬浮球、大面积插画。

## 1. 色彩

| 语义 | 变量 | 色值 | 用途 |
|---|---|---|---|
| 主色 | `--c-primary` | `#174A5C` | 顶栏、主按钮、当前菜单、关键数字 |
| 辅助色 | `--c-secondary` | `#2A7F86` | 次级按钮、筛选选中态、普通图表系列 |
| 页面背景 | `--c-bg` | `#F3F8F8` | 内容区背景（表格/表单用白色容器） |
| 强调色 | `--c-accent` | `#316B74` | 链接、信息提示、图表对比系列 |
| 成功 | `--c-success` | `#247A58` | 已完成、已通过、合格 |
| 危险 | `--c-danger` | `#A62B32` | 驳回、超时、异常、删除确认（小面积） |
| 警告 | `--c-warning` | `#A9761F` | 待到货、临期、待处理 |
| 中性 | `--c-text` / `--c-text-2` / `--c-border` | `#16323A` / `#5B7176` / `#DCE7E7` | 正文 / 次要文字 / 分隔线 |

派生色：`#E8F1F1`（选中底）、`#F7FBFB`（斑马纹）、`#CFE0E1`（禁用）。
图表色板：`#174A5C #2A7F86 #316B74 #6E9AA0 #A9761F #247A58 #A62B32`。

**状态不能只靠颜色表达**，必须同时有中文标签（表格用 tag，详情用「圆点 + 文字」）。

## 2. 字体阶梯

| 层级 | 字号/行高 | 字重 | 场景 |
|---|---|---|---|
| 页面标题 | 20 / 28 | 600 | 内容区顶部 |
| 卡片标题 | 15 / 22 | 600 | 卡片头 |
| 正文 | 13 / 21 | 400 | 表格、表单 |
| 辅助 | 12 / 18 | 400 | 说明、时间戳 |
| 指标数字 | 26 / 32 | 600 | 看板 KPI，`font-variant-numeric: tabular-nums` |

字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`。
所有数字列（金额、数量、评分）使用等宽数字特性。

## 3. 间距与栅格

- 基础单位 4px；常用 8 / 12 / 16 / 24 / 32。
- 内容区外边距 24px；卡片内边距 16–20px；表格单元格 10px 12px。
- 侧边栏 220px（折叠 64px），顶栏 56px，内容区自适应。
- 抽屉宽 560px（表单）/ 720px（比价详情）。
- 表单标签宽 110px，单列输入 360–520px，搜索下拉 180–240px。

## 4. 圆角与阴影

- 圆角：卡片 8px，按钮/输入 6px，标签 4px，头像圆形。
- 阴影：默认无阴影，仅卡片 `0 1px 2px rgba(23,74,92,.06)`；抽屉/弹窗 `0 8px 24px rgba(23,74,92,.16)`。
- 分隔线 1px `#DCE7E7`，不使用重描边。

## 5. 组件基调

- 主按钮：主色实底白字，hover 加深至 `#123C4A`，高度 32px（紧凑）/ 36px（表单）。
- 次级按钮：白底 + `#CFE0E1` 描边 + 主色字。
- 危险按钮：`#A62B32` 描边、白底红字，二次确认。
- 表格：表头 `#F3F8F8`，斑马纹 `#F7FBFB`，行高 44px，表头不固定宽度。
- 标签：浅底色 + 深色字，圆角 4px，高 22px。
- 空状态：说明原因 + 下一步操作按钮，不用纯插画。

## 6. 角色视觉区分

| 角色 | 布局 | 视觉差异 |
|---|---|---|
| 需求申请人 | 门户（顶部导航 + 内容流 + 卡片） | 顶部浅色导航，主色按钮，卡片式需求单 |
| 部门负责人 | 后台（侧边栏 + 顶栏） | 侧边栏含「部门审批」徽标 |
| 采购专员 | 后台 | 侧边栏含询价/比价/采购单，行末固定操作 |
| 审批人 | 后台 | 顶栏突出待办数，抽屉内审批 |
| 仓管/验收人 | 后台（简化菜单） | 验收录入为主，移动端卡片优先 |

## 7. 图表规范

- 一屏 6 个 KPI + 6 个图表，1440×900 不滚动。
- 折线：2px 线宽，无点；柱状：圆角 2px；环图：内径 62%。
- 坐标轴文字 11px `#5B7176`，网格线 `#EDF3F3` 虚线。
- 点击图形跳转明细列表，统计值与明细总数一致。
